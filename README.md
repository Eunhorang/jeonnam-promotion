# 전남 promotion

전라남도 유·초등 교사가 교감 자격연수 대상자 순위명부에 오를 때 받는 평정 점수를 계산하는 웹앱이에요. 경력평정(70점), 근무성적평정(100점), 연수성적평정(30점)과 가산점을 항목별 상한과 함께 계산하고, 평정 기준일을 2032년까지 바꿔 가며 앞날 점수를 미리 볼 수 있어요.

- 근거: 2026. 전라남도교육공무원 승진후보자 평정업무 처리요령(유·초등), 가산점 산정규정(교육훈령 제253호), 교육공무원 승진규정(2026. 6. 16. 시행)
- 저장: 입력값은 브라우저 localStorage(`jeonnam-promotion/v1`)에만 남고 어디로도 보내지 않아요. 다른 기기로는 설정 화면의 파일 내보내기·불러오기로 옮겨요.
- 예시: 주소 끝에 `?sample`을 붙이면 저장한 자료가 없을 때 가상의 교사 자료로 열려요.
- 예상 컷트라인: 공개된 컷 점수가 없어 기준일 만점에서 컷 근처 후보가 흔히 덜 채우는 몫을 빼 어림해요. 그 몫과 어림 범위는 `js/rules.js`의 `CUTLINE`에 있어요. 실제 컷을 알게 되면 여기부터 고쳐요.

## 돌려 보기

빌드 과정이 없는 정적 파일이라 아무 웹 서버로나 열면 돼요.

```bash
python3 -m http.server 4390 --directory .
```

## 계산 점검

```bash
node tests/run.js
```

## 파일

- `js/rules.js`: 배점과 상한 표. 처리요령이 바뀌면 여기부터 고쳐요.
- `js/calc.js`: 계산 엔진(화면과 떨어진 순수 함수), `js/dates.js`: 개월·일 세기
- `js/views.js`: 화면 13개, `js/app.js`: 상태·저장·이벤트, `js/store.js`: 저장과 예시 자료
- `css/style.css`: 화면 모양, `fonts/pretendard`: 글꼴(SIL OFL)
